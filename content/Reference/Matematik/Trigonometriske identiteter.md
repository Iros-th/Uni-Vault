# Trigonometriske Identiteter

## 1. Grundidentiteter

- **Den trigonometriske grundformel (Pythagoras)**:
  $$\cos^2(x) + \sin^2(x) = 1$$
- **Tangens og cotangens**:
  $$\tan(x) = \frac{\sin(x)}{\cos(x)}, \quad \cot(x) = \frac{\cos(x)}{\sin(x)} = \frac{1}{\tan(x)}$$
- **Sekant og cosekant**:
  $$\sec(x) = \frac{1}{\cos(x)}, \quad \csc(x) = \frac{1}{\sin(x)}$$
- **Sekant-identiteter**:
  $$1 + \tan^2(x) = \frac{1}{\cos^2(x)} = \sec^2(x)$$
  $$1 + \cot^2(x) = \csc^2(x)$$

## 2. Additionsformler

- $$\sin(A \pm B) = \sin(A)\cos(B) \pm \cos(A)\sin(B)$$
- $$\cos(A \pm B) = \cos(A)\cos(B) \mp \sin(A)\sin(B)$$
- $$\tan(A \pm B) = \frac{\tan(A) \pm \tan(B)}{1 \mp \tan(A)\tan(B)}$$

## 3. Dobbeltvinkel- og halvvinkelformler

- **Dobbelt vinkel**:
  $$\sin(2x) = 2 \sin(x)\cos(x)$$
  $$\cos(2x) = \cos^2(x) - \sin^2(x) = 2\cos^2(x) - 1 = 1 - 2\sin^2(x)$$
  $$\tan(2x) = \frac{2\tan(x)}{1 - \tan^2(x)}$$
- **Halvering af vinkel (potensreduktion)**:
  $$\sin^2(x) = \frac{1 - \cos(2x)}{2}$$
  $$\cos^2(x) = \frac{1 + \cos(2x)}{2}$$
