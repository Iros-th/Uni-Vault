# Den Samlede Formelsamling

Dette opslagsværk er baseret på den officielle formelsamling for Matematik A (HTX/STX) suppleret med grundlæggende universitetsmatematik for ingeniører. Hvert afsnit indeholder de autoriserede definitioner, regneregler og sætninger.

## Indholdsfortegnelse

1. [[Reference/Formelsamling/Grundlaeggende regning|Grundlæggende regning]] - Brøkregler, potenser, rødder, logaritmer og kvadratsætninger.
2. [[Reference/Formelsamling/Geometri og trigonometri|Geometri og trigonometri]] - Arealer, rumfang, enhedscirklen, sinus, cosinus og vilkårlige trekanter.
3. [[Reference/Formelsamling/Funktioner|Funktioner og modeller]] - Lineære, eksponentielle, potens- og polynomiske funktioner samt diskriminantformlen.
4. [[Reference/Formelsamling/Vektorer|Vektorer i 2D og 3D]] - Skalarprodukt, determinanter, krydsprodukt, linjens og planens ligning.
5. [[Reference/Formelsamling/Differentialregning|Differentialregning]] - Tretrinsreglen, differentiationstabel, produkt- og kædereglen, tangenter.
6. [[Reference/Formelsamling/Integralregning|Integralregning]] - Stamfunktioner, integrationstabel, arealer og omdrejningslegemer.
7. [[Reference/Formelsamling/Differentialligninger|Differentialligninger]] - Standardtyper ($y'=ky$, logistisk vækst), separation af variable og verificering.
8. [[Reference/Formelsamling/Sandsynlighed og statistik|Sandsynlighedsregning og statistik]] - Kombinatorik, binomialfordeling, normalfordeling og $\chi^2$-test.
