# Modul 3: Dit digitale studieliv på DTU

> Kilde: DTU Learn, How to DTU, modul "3) Dit digitale studieliv på DTU" (lektionerne Dine vigtigste digitale platforme på DTU og IT og WIFI). Videoer og den lille quiz er ikke gennemgået.

## Emner

- De tre vigtigste platforme: Student.dtu.dk, DTU Learn og Studieplanlæggeren.
- Wi-Fi, software, IT-sikkerhedsregler.

## Begreber

### Student.dtu.dk

Samler regler, studieordninger og digitale platforme. Din studentermail har adressen s[studienummer]@dtu.dk og findes under Værktøjer eller på outlook.com/dtu.dk. DTU sender al vigtig kommunikation dertil (kursustilmelding, eksamen, afgørelser, dispensation, merit), så mailen skal tjekkes løbende. Brug altid studentermailen, når du kontakter DTU (undtagen Studievejledningen, hvor du kan være anonym).

### DTU Learn

Undervisningsplatformen: lektionsplan, beskeder fra underviser, slides og videoer, opgaver og afleveringer. Kursussider er bygget forskelligt fra kursus til kursus, og sproget skifter mellem dansk og engelsk. Appen Brightspace Pulse giver notifikation om nye announcements.

### Studieplanlæggeren

Her laver du studieplan og tilmelder dig kurser fra 2. semester. Bruges også til Studiestartsprøven (se modul 7). Adresse: studieplan.dtu.dk eller via Student.dtu.dk under Værktøjer.

### Digitale vaner (tjekliste)

Tjek studentermail og Learn-beskeder dagligt, ryd op i indbakken, tjek studiemeddelelser én gang om ugen, slå op i Studieregler ved tvivl.

### IT og Wi-Fi

To netværk: DTUsecure (log på med initialer eller studienummer) og Eduroam (initialer@dtu.dk eller studienummer@dtu.dk). Der er gratis software via softwarebiblioteket, print, Zoom og Microsoft Teams. Sikkerhedsregler: bruger-id er personligt, adgangskoden må ikke deles, licenseret software må ikke kopieres, andres data er privat ejendom. Mistanke om misbrug meldes via Serviceportalen.
### Tidsstyringsmodel: ECTS-arbejdsbelastning og 13-ugers rytmen

1 ECTS-point svarer til ca. 28 timers samlet arbejdsindsats:

```text
  1 Semester (30 ECTS):
  ┌───────────────────────────────────────────────┬─────────────────┐
  │ 13-ugers periode (25 ECTS)                   │ 3-ugers periode │
  │ 5 kurser á 5 ECTS                            │ 1 kursus á 5 ECTS│
  │ Arbejdsbelastning: ~45-50 timer / uge         │ Intensivt kursus│
  └───────────────────────────────────────────────┴─────────────────┘

  Ugentlig fordeling pr. 5-ECTS kursus (~9-10 timer):
  [ 2t Forelæsning ] + [ 2t Gruppeøvelser ] + [ 5-6t Selvstudie / Opgaver ]
```

## Opgaver

Modulet beder om to små handlinger (ikke afleveringer): tjek din studentermail via Student.dtu.dk og tjek dine beskeder i Learn. Der er desuden en lille selvtest om platformene.
