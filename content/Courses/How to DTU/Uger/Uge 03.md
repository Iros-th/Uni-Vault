# Modul 3: Dit digitale studieliv på DTU

> Kilde: DTU Learn, How to DTU, modul "3) Dit digitale studieliv på DTU" (Dine vigtigste digitale platforme på DTU, IT og WIFI). Videoer og den lille selvtest er ikke gennemgået.

## Emner

- De tre vigtigste platforme: Student.dtu.dk, DTU Learn og Studieplanlæggeren.
- Wi-Fi, software og IT-sikkerhedsregler.

## Begreber

### Student.dtu.dk

Samler regler, studieordninger og digitale platforme. Din studentermail har adressen s[studienummer]@dtu.dk og findes under Værktøjer eller på outlook.com/dtu.dk. DTU sender al vigtig kommunikation dertil (kursustilmelding, eksamen, afgørelser, dispensation, merit), så mailen skal tjekkes løbende. Brug altid studentermailen, når du kontakter DTU (undtagen Studievejledningen, hvor du kan være anonym).

### DTU Learn

Undervisningsplatformen: lektionsplan, beskeder fra underviser, slides og videoer, opgaver og afleveringer. Kursussider er bygget forskelligt fra kursus til kursus, og sproget skifter mellem dansk og engelsk. Appen Brightspace Pulse giver notifikation om nye announcements.

### Studieplanlæggeren

Her laver du studieplan og tilmelder dig kurser fra 2. semester. Bruges også til Studiestartsprøven (modul 7). Adresse: studieplan.dtu.dk eller via Student.dtu.dk under Værktøjer.

### Digitale vaner

Tjek studentermail og Learn-beskeder dagligt, ryd op i indbakken, tjek studiemeddelelser én gang om ugen, slå op i Studieregler ved tvivl.

### IT og Wi-Fi

To netværk: DTUsecure (initialer eller studienummer) og Eduroam (initialer@dtu.dk eller studienummer@dtu.dk). Gratis software via softwarebiblioteket, print, Zoom og Microsoft Teams. Sikkerhedsregler: bruger-id er personligt, adgangskoden må ikke deles, licenseret software må ikke kopieres, andres data er privat ejendom. Mistanke om misbrug meldes via Serviceportalen.

## Opgaver

Modulet beder om to små handlinger (ikke afleveringer): tjek din studentermail via Student.dtu.dk og dine beskeder i Learn.
