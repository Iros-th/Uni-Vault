# Uge 3: Komplekse tal, del 1

## Emner

- Tallet $i$ og komplekse tal på rektangulær form $z = a + ib$. Realdel, imaginærdel, konjugering, absolutværdi (modulus), argument og polære koordinater. De inverse trigonometriske funktioner.

## Begreber

### Rektangulær form

Et komplekst tal skrives $z = a + ib$ med $i^2 = -1$ (Definition 4.1.1). $a = \mathrm{Re}(z)$ er realdelen og $b = \mathrm{Im}(z)$ imaginærdelen. Tallet tegnes som punktet $(a, b)$ i den komplekse talplan.

*Eksempel.* $(2+3i)(1-i) = 2 - 2i + 3i - 3i^2 = 5 + i$.

### Division og konjugering

Den konjugerede er $\overline{z} = a - ib$ (Definition 4.2.3). Man dividerer ved at forlænge med nævnerens konjugerede, fordi $z \overline{z} = a^2 + b^2$ er reel.

*Eksempel.* $\dfrac{1+i}{2-i} = \dfrac{(1+i)(2+i)}{(2-i)(2+i)} = \dfrac{1+3i}{5}$.

### Modulus

$|z| = \sqrt{a^2 + b^2}$ er afstanden fra $0$ til $z$ i talplanen. Mængder som $|z - z_0| = r$ er cirkler.

*Eksempel.* $|3 + 4i| = 5$. Mængden $|z - i| \le 2$ er den lukkede cirkelskive med centrum $i$ og radius 2.

### Argument og polære koordinater

Et tal med modulus $r$ og argument $\theta$ har $a = r\cos\theta$ og $b = r\sin\theta$. Hovedargumentet ligger i $]-\pi, \pi]$ og bestemmes ud fra kvadranten.

*Eksempel.* $z = -1 + i$: $r = \sqrt{2}$, og $z$ ligger i 2. kvadrant, så $\mathrm{Arg}(z) = \tfrac{3\pi}{4}$.

### arccos, arcsin og arctan

De inverse trigonometriske funktioner løser $\cos x = c$ osv. inden for deres standardintervaller (se afsnit 2.3). Husk, at $\cos^2 x + \sin^2 x = 1$.

*Eksempel.* $\arcsin\left(\tfrac{1}{2}\right) = \tfrac{\pi}{6}$ og $\arctan(1) = \tfrac{\pi}{4}$.
