# Terms: Mathematical Modelling

Core terms for the modelling course. Full explanations and formulas live in the reference pages and the formula collection.

## Building a model

### Model
A simplified mathematical description of a real situation, made to answer a specific question.

### Assumption
A deliberate simplification you accept to make the problem tractable. Good models state their assumptions openly.

### Variable and parameter
Variables change within the model; parameters are fixed numbers that tune it.

### Dimensional analysis
Checking that the units on both sides of an equation match, a fast sanity test.

## Common model types

### Differential equation model
Describing how a quantity changes over time or space through its rate of change.

### Discrete model
Describing change step by step, for example a recurrence between generations.

### Optimisation model
Finding the input that makes an objective as large or as small as possible.

## Trusting a model

### Validation
Comparing the model against real data to see whether it holds up.

### Sensitivity analysis
Checking how much the output moves when a parameter is nudged.
