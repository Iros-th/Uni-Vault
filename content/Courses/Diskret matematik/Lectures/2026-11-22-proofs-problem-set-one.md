## Key Concepts
- Proofs: Problem Set One 1.
- IN CLASS PROBLEMS In the following exercises you can assume the usual algebraic and ordering properties of the integers Z and the rational numbers Q.
- We have proved before that √ 2 is irrational, i.e., √ 2 ∈ R \ Q.
- (Hence there are more real numbers than rational numbers).
- The real and complex numbers are both examples of a field.
- (See the field axioms in the appendix of the notes).
- Prove or disprove the following statements: (1) If r is an irrational number than 1 r is also irrational.
- (2) If q is rational and r is irrational then q + r is irrational.
- Prove or disprove the following statements: (1) For every integer n ∈ Z, the number n + √ 2 is irrational.
- (2) There is a largest irrational number.

## Definitions and Formulas
- We won’t give a precise definition of the real numbers R, but you can assume that Q ⊂ R, and that the real numbers have the same algebraic and ordering properties as the rationals: they can be added and multiplied together to get real numbers, and any non-zero real number has a multiplicative and additive inverse).
- You can also assume that √ 2 exists, i.e., there is a positive real number x such that x2 = 2.
- Using the axioms, prove that the multiplicative identity element, 1, in a field is necessarily unique, i.e., that it is the only element a that satisfies a · x = x for all x in the field.
- Prove or disprove: There is no rational number x that satisfies the equation x2 = 3 25 .
