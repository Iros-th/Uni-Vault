The non-zero complex numbers C \ {0}, together with the multiplication oper- ation, is an example of a group. A group is defined to be a set G together with a binary op- eration ∗ : G × G → G, that takes two elements a, b in G and produces a new one a ∗ b ∈ G, and the following group axioms must hold: (1) ∗ is associative: a ∗ (b ∗ c) = (a ∗ b) ∗ c for all a, b, c ∈ G. (2) There exists a special element e, called the identity, or neutral element that satisfies: e ∗ x = x ∗ e = x for all x ∈ G. (3) Every element x has an inverse element x-1 such that x ∗ x-1 = x-1 ∗ x = e. For each of the following sets with operation, determine (with proof) whether or not it is a group. • The set of bijective maps f : R → R, with the operation of composition, i.e. ( f ◦ g)(x) = f (g(x)).
