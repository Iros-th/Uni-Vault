# Begreber: Programming

De vigtigste begreber i faget, samlet ét sted. Klik videre til [[Glossary]] eller referencesiderne for de fulde forklaringer.

## Grundbegreber

### Variabel
Et navn du sætter på en værdi så du kan bruge den igen. Se [[01 Variabler og datatyper|noten om variabler]].

### Datatype
Hvilken slags værdi noget er (tal, tekst, sandt/falsk osv). Fuld liste i [[Reference/Programmering/Alle datatyper|Alle datatyper]].

### Operator
Tegn der regner eller sammenligner, fx `+`, `==`, `and`. Se [[Reference/Programmering/Alle operatorer|Alle operatorer]].

## Kontrol af programforløb

### Betingelse
`if`, `elif`, `else` styrer hvad der køres hvornår. Se [[Reference/Programmering/Kontrolstrukturer|Kontrolstrukturer]].

### Løkke
Gentager kode (`for`, `while`). Se [[05 Løkker|noten om løkker]].

### Funktion
Genbrugelig bid kode du kalder med `def`. Se [[06 Funktioner|noten om funktioner]].

## Data og struktur

### Liste, dictionary, tuple, set
Samlinger af værdier. Se [[07 Lister|Lister]] og [[08 Dictionaries tuples og sets|Dictionaries, tuples og sets]].

### Klasse og objekt
Egne datatyper med data og metoder. Se [[11 Klasser og OOP|Klasser og OOP]].

### Fejl (exception)
Når noget går galt under kørsel. Se [[Reference/Programmering/Fejltyper|Fejltyper]].
