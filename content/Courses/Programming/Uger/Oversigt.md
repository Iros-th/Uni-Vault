## Pensum

Pensum er syllabus-listerne på kursussiden (Course Syllabus og Closure-siden for hver uge). Emner markeret Advanced er ikke pensum, og til eksamen må man ikke importere biblioteker uden for syllabus. Hovedbog: Think Python, 3. udgave (Allen Downey); hver uge henviser til kapitler, suppleret med CS50, W3Schools og Python-tutorials. Kursusbasen: Python, datatyper, sætninger, forgreninger og løkker, funktioner, input fra filer, tupler, lister, dictionaries, simple klasser, moduler og test af funktioner.

| Uge | Syllabus |
|---|---|
| 1 | Programmer, `=`, `print()`, tal og strenge, operatorer og præcedens, `abs()`, `round()`, måder at køre Python |
| 2 | Tildeling, udtryk, typer, `type()`, omtildeling, `+=`, strengoperatorer, `len()`, typekonvertering, `%` og `//`, `max()`, `min()`, `math`, boolske og logiske operatorer, fejlmeddelelser |
| 3 | `if`, `else`, `elif`, indlejrede betingelser, fejlfinding med `print()` |
| 4 | `for`, `range()`, `while`, `break`, pseudokode, simulering |
| 5 | `def`, parametre og argumenter, scope, `return`, `None`, tracebacks, test og dokumentation af funktioner |
| 6 | Lister, indeksering, udsnit, mutabilitet, listemetoder, `is`, rene funktioner og modifier-funktioner, gennemløb, `list()` |
| 7 | Strenge, metoder, `split()`, `join()`, `in`, f-strings, escape-tegn, `repr()` |
| 8 | Dictionaries og tupler, tuple-unpacking |
| 9 | `os`, `open()`, `with`, læse- og skrivemetoder, CSV som tekst |
| 10 | Klasser, instanser, attributter, metoder, `self`, `__init__()` |
| 11 | Nedarvning, overriding, `super()`, `__str__()`, `__add__()`, `__eq__()` |
| 12 | NumPy-arrays, vektoriserede operationer, indeksering, forallokering; Matplotlib (linje- og søjlediagrammer, labels, legends, titler, tekst) |
| 13 | Egne moduler, import (standard, selektiv, alias), `dir()` |

## Eksamen og bonuspoint

- Kursusbasen og kursussidens Course Policies: 4 timers skriftlig, individuel eksamen på DTU med alle hjælpemidler uden internet, afleveret via Digital Eksamen. Kommunikation med andre og brug af AI er ikke tilladt. Scoren går fra 0 til 100 %.
- Bonuspoint: i hver uge undtagen den første er der en quiz i timen med 10 multiple choice-spørgsmål. Mindst 6 rigtige giver 0,5 % bonus, i alt op til 5 % (12 quizzer). Bonus kan højst løfte karakteren til 7 og gælder tre eksamenstermer.
- Checkpoint-opgaver kan afleveres på DTU Learn med feedback fra uge 5. Eksamenssæt fra tidligere terminer kan afleveres frem mod eksamen.

## Fra DTU Learn

- Torsdag: quiz og live-demo 13:00 til 14:00, selvstændigt arbejde med Coding Practice 14:00 til 14:30 (resten af eftermiddagen er beskrevet i meddelelsen på DTU Learn).
- Den frivillige midtvejseksamen ligger under Assignments på DTU Learn. Gamle eksamenssæt kan afleveres frem mod eksamen.
