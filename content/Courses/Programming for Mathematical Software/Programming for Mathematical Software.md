# Programming for Mathematical Software (02635)

Efterår 2026. Programmering i C (og lidt C++) med fokus på matematisk software: flydende tal, numerisk stabilitet, pointere, dynamisk hukommelse, filer og sparse matricer, ydeevne, BLAS/LAPACK, OpenMP, test og rekursion.

- Lærebog: K. N. King, "C Programming: A Modern Approach", 2. udgave, 2008 (ISBN-13: 978-0-393-97950-3)
- Supplerende noter: "02635 lecture notes" (skrevet af underviserne, ligger på DTU Learn)
- Fra modul 12: "Beginning C++" (udgave ikke angivet på kursussiden)
- Undervisere ifølge kursussiden: Martin Andersen (de fleste moduler), Bernd Dammann (modul 3 del 1 og modul 9)
- Autolab tæller med i karakteren (moduler 1 til 8), samt en afleveringsopgave. Skriftlig eksamen 8. december 2026.
- Tag: `c-programming`
