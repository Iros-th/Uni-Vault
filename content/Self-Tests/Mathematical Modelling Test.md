# Self-test: Mathematical Modelling

Answer each one yourself first, then click "Show answer". No score is kept, this is just for you.

**1.** What is the difference between a variable and a parameter in a model?

> [!success]- Show answer
> A variable changes within the model (like position over time). A parameter is a fixed number that tunes the model (like a growth rate).

**2.** Why is it good practice to state a model's assumptions openly?

> [!success]- Show answer
> Assumptions define where the model is valid. Stating them shows what you simplified and where the model can be trusted or will break down.

**3.** What is dimensional analysis, and why is it a fast check?

> [!success]- Show answer
> Checking that the units match on both sides of an equation. If they do not, the equation is wrong, so it catches mistakes before any numbers are plugged in.

**4.** Write a simple differential equation model for unlimited population growth.

> [!success]- Show answer
> $\frac{dP}{dt} = rP$, where $r$ is the growth rate. Its solution is $P(t) = P_0 e^{rt}$.

**5.** What does validation of a model mean?

> [!success]- Show answer
> Comparing the model's output against real data to see whether it actually describes the situation, not just whether the maths is internally consistent.

**6.** What does sensitivity analysis tell you?

> [!success]- Show answer
> How much the output changes when a parameter is nudged. A model that swings wildly on a small change is fragile and needs that parameter measured carefully.
